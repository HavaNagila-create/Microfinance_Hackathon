# 🌱 Dual-AI Dynamic Microloan & Cash-Flow Planner

An end-to-end AI-driven microfinance prototype designed to protect informal sector borrowers from involuntary default while maximizing lender principal recovery.

## 🚀 Key Features
* **Model 1 (Temporal LSTM Predictor):** Forecasts next-month net operating cash flow based on historic income, expenditure, and seasonal cycles.
* **Model 2 (Deep PPO Reinforcement Learning Engine):** Dynamically scales loan repayment demands according to real-time liquidity and harvest surpluses.
* **Subsistence Safety Net:** Strictly enforces a baseline household reserve (₹11,000 threshold) before collecting debt.
* **Informal Archetypes Covered:** Tailored simulations for Farmers, Artisans, Street Vendors, and Gig Drivers.

## 🛠️ Technology Stack
* **Frontend/UI:** Streamlit, Plotly
* **AI/ML Engine:** PyTorch (LSTM), Stable-Baselines3 (PPO)
* **Data Processing:** NumPy, Pandas
